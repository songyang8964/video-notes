## 通用写作与选图规则（适用于任何讲座、课程、培训视频）

- 产物是可以直接分享的{language}技术/学习文档，不是逐字稿、摘要或提纲。标题、正文、表格和图注全部用{language}书写（无论本提示词和字幕是什么语言）。保留准确的英文术语、产品名、命令与参数原文。
- 严格按原讲解时间顺序和推理思路展开；可以在局部合并口头重复、修复断句、补足必要前置，但不按全局主题重排。后续回访、新例子和更正放在实际出现的位置。
- 直接陈述知识。禁止"讲师/老师/讲者提到""视频中""根据字幕""接下来介绍"等转述式元话语，也不在正文写证据核验、截图识读、"无法确认"之类的审查口吻；这些写进 HTML 注释。
- 结合上下文和画面纠正明显的语音识别错误。地址、编号、命令参数、版本号等不能仅凭音近替换；看不清就不写成看似可执行的内容。
- 删除与本视频主题无关的内容：寒暄、会议组织、休息、展示切换、与主题无关的辅助工具或产品介绍与演示、其他项目的闲谈。在注释中说明排除原因。本视频的主题和范围以"视频上下文"为准；没有上下文时根据字幕自行判断。
- 区分原材料事实与补充解释；较大的外部补充标注"补充说明"。
- 配图只选重点：读者理解所必需的结构图、流程图、对比图、表格、关键命令或结果。同一页/同一画面在本章只插一次；不插标题页、目录页、纯文字结论页（文字写进正文）、纯讲者画面和与已插图差异很小的画面。每章通常 3–6 张，最多 {max_images} 张；可以无图。未插入图片中的重要知识要用文字写进正文。
- 图注只说明图中技术内容，不写时间和来源（程序会添加）。
- 正文是给读者的连续文档：引用前文时写所引用的小节标题或内容，不写 C01、Chapter 8、帧 ID 之类的内部编号（这些只用于程序和 HTML 注释）。
